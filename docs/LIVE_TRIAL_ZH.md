# 上车测试速查

这是实验燃油面板，不是已经验收的完整 AI 比赛工程师。今晚先验证采集、
燃油学习和断线保护；正式比赛仍由你自行判断进站，不按本面板改变策略。

## 开始前

在项目根目录的 PowerShell 中运行：

```powershell
.\scripts\start_live_engineer.ps1
```

打开 [本机面板](http://127.0.0.1:8765/)。默认运行 6 小时，无定时任务，
不会启动游戏或修改赛车、进站设置。若已有服务，启动器会复用它，新参数不生效。

LLM 问答框架已接好；按 [DeepSeek 配置说明](DEEPSEEK_ENGINEER.md) 在本机输入 key，
再用 `-DeepSeek` 启动。未配置 key 也能使用本地解读，但不能算真实模型测试。
上车前先运行 `uv run python scripts/rehearse_llm.py` 做无游戏、无费用的合成演练。
停车后点“问燃油”，确认回答来源及数据依据；**不要在驾驶操作时打字或读长回复**。
问策略/驾驶时证据不足是正常拒绝，不能把模型能说话当成完整策略已经通过验收。

## 练习时看三件事

1. **进车后有数据。** “等待 iRacing”应变成已连接；本人驾驶后才能学习。
   观战朋友、回放或停在车库不能代替自己的驾驶数据。
2. **油耗学习确实增加。** 首次过线后再完成至少 5 个有效完整圈；首个不完整圈、
   进出站、加油、出界、事故和不可靠数据不计数。达到门槛后显示单圈油耗、保守续航。
   练习赛没有“至终点需油”是正常的；补油量还要求启动时设置经过确认的油箱容量。
3. **退出驾驶时不留旧建议。** 自然结束练习、退出驾驶或关闭模拟器后，旧估计应撤下。
   不需要在正式比赛中故意断线、出界或制造事故来测试。

如果自然发生进站或加油，系统应先撤下估计，丢弃被污染的圈；之后等新的有效跨线。
重连会重新学习。不要为了让数字尽快出现而减少有效圈门槛。

## 录制和语音

- 默认把原始数据保存到 `%LOCALAPPDATA%\iRacingAIEngineer\captures`，只留本机。
  每次启动总预算 4 GiB，到上限停止录制但面板继续；**不保证录完整场或完整 6 小时**。
  重复启动不自动清理旧文件。面板“本地记录状态”会提示是否仍在录制。
- “保存本次摘要”仅下载聚合信息，不包含原始遥测；原始记录不要上传到 GitHub。
- 语音默认关闭，只允许练习中的本地英文声音。正式 Race 会话保持静音。
  页面隐藏会自动静音，暂不能保证游戏在前台时有语音；本轮不是后台语音验收。
- 关闭浏览器不停止采集。可等默认 6 小时自动退出；提前停止和自定义参数见
  [完整使用说明](LIVE_APP.md)。

跑完告诉我车、赛道、约运行多久，以及面板是否一直停在等待/学习或出现录制错误。
后续可在本机检查这次私密记录；不能把 UI 显示成功当成真实策略或驾驶指导验收。
